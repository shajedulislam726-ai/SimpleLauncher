# Simple Launcher

A tiny, ad-free Android launcher. No dependencies, no tracking, no network permission.

- Home: clock, date, and a dock with up to 5 apps
- Swipe up: app drawer with live search (press Go/Enter to open the first result)
- Long-press an app in the drawer: add to dock / app info / uninstall
- Long-press a dock app: remove from dock

Build: push to GitHub, open Actions > Build APK, download the `SimpleLauncher-apk` artifact.
